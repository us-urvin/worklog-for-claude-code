Everything you did with Claude Code, without writing it down

Worklog reads Claude Code's own session logs on your computer and turns them into a work log you can read, search and share.

✍️ Every project, in plain words

One card per project with a short summary, the kind of work, pull requests and tasks. Claude writes the summary with your own account, or skip AI and keep it fully local.

📊 Token usage per project

Tokens by account and model, and active hours, for every project and day. See which work uses your Pro or Max limits.

🔎 Ask your worklog

"When did I review PR 505?" Search forgives typos and finds the day. Tick Ask Claude for a short written answer with links.

🧾 A timesheet, ready for Excel

Hours, kind of work and one line per project and day. Download it as Excel or CSV for your client or manager.

📍 Where you left off

Your last projects, open tasks, branch, PRs and tickets at the top of the page, so mornings start fast.

🖼️ Share your week

A card for a day, week, month or year, wide or square. One click opens LinkedIn or X with the post written. Totals only, never prompts or files.

How it works

You need Python 3.10+, git and Claude Code. Linux, macOS and Windows.

Install

pipx install worklog-for-claude-code

Make a private folder for your log

git init ~/claude-worklog-data
claude-worklog install-service

Open the dashboard

localhost:8765, fill in the short form, then use Claude Code as usual. A checklist shows anything still missing.

Just looking? Try it on made-up data, with nothing installed: pipx run --spec worklog-for-claude-code claude-worklog demo, then open localhost:8766.

Private by design

  • 🔒 Never your code. Only short notes: the start of your prompts, token counts, file names and commit messages. Never your files or Claude's replies.
  • 🧹 Secrets blanked out before saving: API keys, tokens, passwords, e-mails.
  • 🏠 Your computer, your git repo. No telemetry, no account, no server run by this project.
  • ✅ Signed releases. Every release is built and signed by GitHub and tested on three systems. Verify a release.
  • 📏 A personal log, not a performance score. Hours are your active time with Claude, not a measure of your output.
  • 🧩 No dependencies outside Python's standard library, and the full source is on GitHub.

Questions

How do I see Claude Code token usage per project?

Install Worklog and open its dashboard. Every project gets a card with its tokens, active hours and what you did, read from Claude Code's own session logs on your computer.

Does Worklog send my code anywhere?

No. It never saves your files or Claude's replies. Notes stay on your computer and in a private git repo you choose. AI summaries are optional and use your own Claude account; turn them off to stay fully offline.

Does it work with several Claude accounts and computers?

Yes. It tells accounts apart, even with one-click account switchers, and combines several computers through your private git repo.

Can I see it on my phone?

Yes: turn on the phone summary on one computer and open your data repo's phone folder in the GitHub app. It stays private.

How is it different from ccusage and other usage trackers?

Token reports tell you how much you used. Worklog also writes down what you worked on, project by project, keeps a timesheet, shows where you left off, and lets you search or ask about past work. You can use it alongside other tools.

Is it free?

Yes. It's open source under the MIT licence.
